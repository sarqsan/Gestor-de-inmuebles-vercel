## 3. Defecto P5.4-D1 (integridad) y corrección

**Reproducción.** Con una factura ya registrada por OCR y **ANULADA**:

1. `evaluarDuplicadosFacturaOcr` descartaba los gastos `ANULADO` al inicio del
   bucle, así que devolvía `exacto: undefined` y `posibles: []`.
2. `construirGastoOcr` deriva el ID de la clave (`idGastoOcr`), de modo que el
   alta nueva produce **exactamente el mismo ID** que el registro anulado
   (comprobado: `factura:inm-1:b12345674:f2026031` → mismo `gas_ocr_…`).
3. `guardarGastoVerificado` escribe con `setDoc(..., { merge: true })` sobre ese
   ID: el estado `ANULADO` se sustituía por `PENDIENTE` y el registro anulado
   quedaba resucitado en silencio.

Esto incumple el requisito «un gasto pagado **o anulado** nunca puede
sobrescribirse mediante un reintento». El caso se reproduce también en la
recuperación prevista tras un fallo de custodia, cuyo mensaje invitaba a
«volver a procesar la factura».

**Corrección.**

- `EvaluacionDuplicadosOcr` incorpora `anulado`, que identifica el alta OCR
  anulada **de la misma factura y el mismo inmueble**. Sigue sin contar como
  `exacto` ni como `posible` (semántica P5.2 intacta), pero ya no es invisible.
- El escáner bloquea la confirmación (botón deshabilitado + alerta) y vuelve a
  comprobarlo dentro de `confirmar()`, no solo en la vista.
- La recuperación es explícita: reactivar el gasto desde Gastos (estado
  «Pendiente») y, si le falta el documento, reprocesar la factura. El mensaje
  de anulación automática se actualiza para indicarlo.
- Un `ANULADO` de **otro** inmueble no bloquea (no comparte ID ni ámbito).

## 7. Limitaciones conocidas que siguen abiertas

- Tesseract.js se descarga de una CDN pública con versión fijada, sin SRI ni
  autoalojamiento: un CDN no disponible impide el OCR (mensaje claro, sin éxito
  ficticio). No se envían documentos ni texto a la CDN.
- HEIC no admitido; PDF de más de 5 páginas rechazado; precisión OCR real sin
  medir. PDFs con capa de texto se rasterizan (no se extrae el texto).
- Rectificativas/abonos solo bloqueados; no modelados contablemente.
- La descarga del original exige `inmuebleId` y estado `DISPONIBLE`; una
  `permission-denied` de Firestore/Storage puede mostrarse con el texto técnico
  de Firebase en ese caso concreto.
- El defecto fiscal independiente de facturas manuales invisibles queda fuera
  de P5.
